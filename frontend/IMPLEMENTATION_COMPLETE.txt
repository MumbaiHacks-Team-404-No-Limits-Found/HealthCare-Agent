MODAL COMPONENTS
================================================================================

📝 CAMP MODAL
  • Name (required, 1-200 chars)
  • Location (required, 1-200 chars)
  • Start date/time (required, datetime-local)
  • End date/time (required, datetime-local)
  • Requirements (at least one required)
    - Role (e.g., doctor, nurse)
    - Count (number of volunteers needed)
    - Slot (e.g., morning, afternoon)
  • Add/remove requirements dynamically
  • Form validation
  • Error handling

👤 VOLUNTEER MODAL
  • Name (required, 1-200 chars)
  • Phone (required, E.164 format, 10-20 chars)
  • Skills/roles (at least one required)
    - Add multiple skills
    - Remove skills
  • No-show rate (0.0-1.0, default 0.2)
  • Availability (optional)
    - Date picker
    - Multiple slots per date
    - Add/remove availability
  • Form validation
  • Error handling

📋 ASSIGNMENT MODAL
  • Camp selection (required, dropdown)
  • Volunteer selection (required, dropdown)
  • Role (required, auto-populated from camp requirements)
  • Slot (required, auto-populated from camp requirements)
  • Status (assigned/confirmed/cancelled)
  • Backup volunteer checkbox
  • Form validation
  • Error handling

DATA FLOW & STATE MANAGEMENT
================================================================================

1. PAGE LOAD
   └─> Authentication check
   └─> Fetch data from REST API
   └─> Display loading state
   └─> Populate UI with data
   └─> Show error if any

2. CREATE OPERATION
   └─> Open modal
   └─> Fill form
   └─> Validate input
   └─> POST to API
   └─> Refresh data
   └─> Close modal

3. UPDATE OPERATION
   └─> Click edit button
   └─> Open modal with pre-filled data
   └─> Modify fields
   └─> Validate input
   └─> PUT/PATCH to API
   └─> Refresh data
   └─> Close modal

4. DELETE OPERATION
   └─> Click delete button
   └─> Show confirmation dialog
   └─> DELETE to API
   └─> Refresh data
